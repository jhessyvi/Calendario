## 📅 Calendário de Março de 2024
Este é um projeto simples de um calendário do mês de março de 2024, desenvolvido com HTML e CSS puro. Ideal para fins de estudo, prática de estruturação com HTML e estilização com CSS.

## 🔍 Visão Geral
O calendário mostra os dias corretamente posicionados de acordo com o início de março de 2024 (que começa em uma sexta-feira), incluindo:

Dias da semana (Domingo a Sábado)

Numeração correta dos dias do mês

Destaque para finais de semana (opcional)

Estilização responsiva (se aplicável)

## 💻 Tecnologias Utilizadas

-HTML5

-CSS3
